# DevToolkit Pro - Developer Utilities & Cloud Assets

> ⚡ Fast, privacy-focused developer utilities. Local tools execute 100% in-browser with zero data collection; the SpamShield Email Checker connects to a dedicated external fraud verification API.

Live Website: [https://svl550.github.io/dev-tools-hub/](https://svl550.github.io/dev-tools-hub/)

## Included Tools
- **JSON Formatter & Validator**: Pretty-print, format with custom indentation, validate, and minify.
- **JSON ↔ CSV Converter**: Instant two-way conversion with download support.
- **Base64 Encoder / Decoder**: Fast UTF-8 string encoding and decoding.
- **Cryptographic Hash Generator**: Real-time SHA-256, SHA-512, and SHA-1 using native Web Crypto API (100 MB safe limit).
- **URL & SEO Slug Generator**: URL encode/decode and clean multilingual SEO permalink generator.
- **UUID & Secret Key Generator**: RFC 4122 UUID v4, 32-byte API hex keys, and high-entropy passwords via unbiased rejection sampling.
- **HTML & CSS Beautifier**: Lexical-tokenized HTML beautifier and CSS minifier/formatter.
- **SpamShield Email & Fraud Checker**: Live syntax, MX record, and disposable burner domain verification (connects to SpamShield Cloud API).
- **Global SaaS & Startups Directory 2026**: Interactive directory of tech companies, tech stacks, and funding stages.

## Privacy & Security
- Local tools execute strictly client-side using native browser APIs with zero telemetry and zero server storage.
- SpamShield Email Checker transmits entered email addresses to the documented SpamShield API on Render Cloud over encrypted HTTPS.
- Hardened Content Security Policy (CSP) eliminating runtime `eval()`.
- WAI-ARIA accessible vertical tablist navigation conforming to WCAG 2.2 AA.
